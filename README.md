Write the funniest one-line patch note for a bug in real life or human biology, 160 characters max. Free entry, open 72 hours, and the top 5 places split the reward pool equally.

The program writes one patch note to `/output/entry.txt`:

> v3.1.4: fixed a bug where the brain remembered every lyric from 2009 but not why you walked into the kitchen.

109 characters, one line. The brain keeps the useless lyrics forever and drops the reason you stood up — a specific, recognisable bug of the body, written in the terse register of a real release note.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`), validates the line against the gate (1–160 characters, single line, non-blank) and reads it back to confirm.
